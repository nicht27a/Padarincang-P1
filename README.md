## 📰 Panduan Penggunaan - Padarincang Website

Proyek ini merupakan website Padarincang-P1 yang memiliki fitur berita, galeri, dan makanan khas.
Panduan berikut menjelaskan cara menambahkan berita baru serta mengganti gambar di bagian makanan khas dan galeri.
## Features yang bisa diedit

- Berita baru
- Menganti gambar gallery dan makanan khas



## Fungsi Website

## 📌 1. Cara Menambahkan Berita Baru

Masuk ke halaman admin (sementara):

http://localhost/Padarincang-P1/public/admin.php


Isi semua data yang diminta pada form berita (judul, deskripsi, gambar, dll).

Klik tombol Submit untuk menyimpan berita.

Setelah berhasil, kembali ke halaman utama:

http://localhost/Padarincang-P1/public/main.php


Berita baru akan otomatis muncul di halaman utama website.


## 🖼️ 2. Cara Mengganti Gambar di “Makanan Khas” dan “Gallery”

Buka folder utama website, lalu masuk ke direktori berikut:

`/Padarincang-P1/public/assets/`


Di dalam folder assets, terdapat file gambar dengan penamaan sebagai berikut: `gambar1.jpg`


Gambar 1–8 → digunakan untuk Makanan Khas

Gambar 9–17 → digunakan untuk Gallery

Jika ingin mengganti salah satu gambar, lakukan langkah berikut:

Hapus file gambar lama, misalnya `gambar7.jpg`

Tambahkan gambar baru dengan nama yang sama persis `gambar7.jpg`
⚠️ Jangan gunakan spasi dalam nama file.

Setelah gambar diganti, refresh halaman utama.
Gambar baru akan otomatis tampil di website.
